# RWA Doubt Bot 🤖

Telegram management and auto-moderation bot for RWA Doubt Group.

## 🚀 Features
* **Auto Moderation:** Anti-Link, Anti-Badword & Warning system (3 warnings = Auto Ban).
* **Smart Auto-Delete:** Bot messages aur user auto-replies automatic delete hote hain.
* **Auto Slow Mode:** Schedule ke hisab se slow mode auto ON/OFF ho jata hai.
* **Member Events:** Custom Welcome, Exit, aur Ban/Remove messages.
* **Atomic Storage:** Data safety ke liye atomic JSON database handling.

## 🛠️ Setup & Deployment

### Environment Variables
* `BOT_TOKEN`: Your Telegram Bot API Token

### Render Deployment
This bot is configured to run as a **Worker** service on Render.
